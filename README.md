### Rest App Next.js

Aplicação full-stack desenvolvida durante a graduação, utilizando o próprio Next.js para o frontend e backend por meio de API Routes.

**Tecnologias:** Next.js, React, JavaScript, Firebase, CSS Modules e Vercel.
